Pilates Studio 子域名与微信小程序合法域名配置指南

适用场景：域名在阿里云万网购买，服务部署在阿里云 ECS，后台和 API 使用同一台服务器。

本文档是发布配置操作手册。需要登录阿里云和微信公众平台的账号级操作必须由账号管理员完成；配置完成后，再回到本地项目更新生产配置草稿并执行发布门禁。

1. 规划子域名

用途 子域名 说明
后台管理端 admin.你的域名.com 门店运营人员在浏览器中访问后台管理系统。
后端 API api.你的域名.com 后台管理端和微信小程序都通过这个域名访问后端接口。
小程序代码里的 API 地址填写 https://api.你的域名.com/api； 微信公众平台的 request 合法域名只填写 https://api.你的域名.com，不要带 /api 路径。

2. 查看域名是否已备案

方式 A：阿里云控制台查看

  1. 登录 阿里云官网。
  2. 进入控制台，在顶部搜索 ICP备案 或 备案管理。
  3. 在备案列表中查找你的主域名，例如 example.com。
  4. 如果状态显示 备案成功、已备案 或能看到备案号，说明可以继续准备微信合法域名配置。

方式 B：工信部备案查询

  1. 打开 工信部 ICP/IP 地址/域名信息备案管理系统。
  2. 进入 ICP备案查询。
  3. 输入主域名，例如 example.com。
  4. 能查到备案号，通常表示域名已备案。
如果域名未备案或备案中，可以先配置 DNS 解析；但微信小程序正式配置服务器域名、国内生产访问和审核上线通常需要备案完成。

3. 在阿里云万网配置子域名解析

  1. 登录阿里云控制台。
  2. 顶部搜索 云解析 DNS，进入 公网权威解析 或 域名解析。
  3. 找到你的主域名，例如 example.com，点击右侧 解析设置。
  4. 点击 添加记录。
  5. 先添加后台管理端解析：
字段 填写值
记录类型 A
主机记录 admin
解析线路 默认
记录值 你的 ECS 公网 IPv4 地址
TTL 默认或 10 分钟

再添加 API 解析：

字段 填写值
记录类型 A
主机记录 api
解析线路 默认
记录值 你的 ECS 公网 IPv4 地址
TTL 默认或 10 分钟
如果后续不是直接访问 ECS，而是使用阿里云负载均衡、CDN、WAF 或其他平台托管，再把记录类型改为 CNAME 并指向平台给出的域名。

4. 验证 DNS 是否生效

在本机 PowerShell 执行：

nslookup admin.你的域名.com
nslookup api.你的域名.com

预期结果：两个域名都解析到同一个 ECS 公网 IP。

也可以指定公共 DNS 服务器验证：

nslookup admin.你的域名.com 223.5.5.5
nslookup api.你的域名.com 223.5.5.5

5. 配置 HTTPS 证书

微信小程序正式环境必须使用 HTTPS。推荐二选一：

  1. 在阿里云申请免费或付费 SSL 证书，然后部署到 Nginx。
  2. 在服务器上使用 Certbot 自动申请证书。

如果使用 Certbot，服务器上可执行：

certbot --nginx -d admin.你的域名.com -d api.你的域名.com
申请证书前，必须先确保 admin 和 api 两个子域名已经解析到服务器，并且服务器 80/443 端口已在 ECS 安全组中放行。

6. Nginx 推荐配置

后台和 API 可以共用同一台 Nginx。后台访问 admin.你的域名.com，API 访问 api.你的域名.com。

server {
  listen 80;
  server_name admin.你的域名.com api.你的域名.com;
  return 301 https://$host$request_uri;
}

server {
  listen 443 ssl http2;
  server_name admin.你的域名.com;

  ssl_certificate /etc/letsencrypt/live/admin.你的域名.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/admin.你的域名.com/privkey.pem;

  root /usr/share/nginx/html;
  index index.html;

  location / {
    try_files $uri $uri/ /index.html;
  }
}

server {
  listen 443 ssl http2;
  server_name api.你的域名.com;

  ssl_certificate /etc/letsencrypt/live/api.你的域名.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/api.你的域名.com/privkey.pem;

  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto https;
  }
}

7. 修改项目生产配置

后台生产配置草稿位置：F:\pilates-studio-admin\.env.production.draft

CORS_ORIGINS=https://admin.你的域名.com,https://api.你的域名.com
WECHAT_PAY_NOTIFY_URL=https://api.你的域名.com/api/payments/wechat/notify

小程序生产配置草稿位置：F:\pilates-studio-mini\.env.production.draft

API_BASE_URL=https://api.你的域名.com/api
DEVTOOLS_API_BASE_URL=https://api.你的域名.com/api
APP_ENV=production
MINI_RELEASE=true
ALLOW_INSECURE_REAL_DEVICE_API=false
USE_MINI_OPEN_ID_LOGIN=false

8. 微信公众平台配置 request 合法域名

  1. 打开 微信公众平台。
  2. 使用小程序管理员或开发者账号登录。
  3. 确认当前账号是 小程序，不是公众号。
  4. 左侧菜单进入 开发。
  5. 进入 开发管理。
  6. 进入 开发设置。
  7. 找到 服务器域名。
  8. 点击 修改，按要求扫码验证管理员身份。
  9. 在 request 合法域名 中添加：https://api.你的域名.com
  10. 如果后续有图片下载，再在 downloadFile 合法域名 中添加图片 CDN 或 API 域名。
  11. 如果后续有文件上传，再在 uploadFile 合法域名 中添加上传域名。
  12. 保存配置。
微信合法域名不要填写 IP，不要填写 localhost，不要带端口，不要带路径。 正确示例：https://api.你的域名.com。 错误示例：https://api.你的域名.com/api、http://api.你的域名.com。

9. 微信开发者工具验证

  1. 重新编译小程序生产包。
  2. 打开微信开发者工具。
  3. 导入项目目录下的 dist。
  4. 确认 project.config.json 中是正式 AppID。
  5. 在开发者工具中关闭 不校验合法域名、web-view 域名、TLS 版本以及 HTTPS 证书 后测试。
  6. 测试微信登录、首页、课程列表、预约、取消预约、个人中心。

10. 上线前最终检查

cd F:\pilates-studio-admin

npm.cmd run release:check -- `
  -MiniRoot F:\pilates-studio-mini `
  -BackendEnvPath .env.production.draft `
  -MiniEnvPath F:\pilates-studio-mini\.env.production.draft
只有 release:check 没有 Blockers，并且微信真机测试通过后，才建议打正式 v1.0.0 tag。

11. 操作完成核对清单

  • 主域名已完成 ICP 备案，能查到备案号。
  • admin.你的域名.com A 记录指向 ECS 公网 IP。
  • api.你的域名.com A 记录指向 ECS 公网 IP。
  • 两个子域名都已签发 HTTPS 证书。
  • 微信公众平台 request 合法域名已添加 https://api.你的域名.com。
  • 小程序生产配置中的 API_BASE_URL 已改为 https://api.你的域名.com/api。
  • 发布门禁 release:check 无 Blockers。
